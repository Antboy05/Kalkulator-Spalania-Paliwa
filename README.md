# Kalkulator-Spalania-Paliwa
Projekt stworzony na własne potrzeby w celu ułatwienia kontroli wydatków na paliwo. Kod został przygotowany przy wsparciu sztucznej inteligencji (Gemini), a następnie przetestowany i dostosowany do codziennego użytku.
